## Acceptance Statement

CASR v0.2.0 successfully imports native Codex rollout history into CASR-owned,
provider-neutral, append-only canonical storage.

The release was validated against deterministic synthetic fixtures and five
real local Codex rollout sources.

## Ordering and Identity

For every validated source:

- canonical sequence numbers were contiguous
- native source positions were contiguous
- source positions began at zero
- canonical event count matched physical record count
- fingerprints used the SHA-256 canonical fingerprint format
- native session provenance remained intact
- native source provenance remained intact

execution.


## Serialization

Every canonical payload and preserved raw event passed JSON serialization and
parse round-trip validation.

## Corruption Policy

Malformed middle record:

```text
safe prefix imported
cursor stops before malformed record
later evidence is not skipped
repeated import does not duplicate events
```

Deferred final tail:

```text
safe prefix imported
incomplete final record deferred
completed record detected later
completed record imported once
cursor reaches EOF
```

Source truncation:

```text
cursor is not rewound
canonical history is not deleted
truncation is reported
```

## Golden Fixtures

Committed deterministic synthetic fixtures cover legacy and modern Codex
envelopes, messages, tool calls/results, lifecycle, state, metadata, unknown
future semantics, malformed middle records, and deferred final tails.

Fixture data contains no real conversation content or authentication material.

unchanged.
